Sprint_6. Сервис "Самокат". Автотесты.

Набор UI-автотестов для проверки части сервиса «Самокат» (два сценария оформления заказа, раздел "Вопросы о важном", переходы кликом по логотипам).
Реализовано по паттерну Page Object Model, используется pytest, Selenium, браузер Firefox. Отчёты формируются в Allure.

Проверки:
- Реализованы два сценария оформления заказа: один с использованием кнопки "Заказать" в шапке страницы, второй - с использованием кнопки "Заказать" внизу страницы;
- Автотесты на раздел "Вопросы о важном" проверяют реализацию выпадающего ответа при клике на вопрос. Проверены все 8 вопросов;
- Автотесты проверяющие, что при клике по логотипам Яндекс и Самокат, расположенных в шапке страницы, происходят следующие переходы на страницы: Яндекс - на страницу Дзен; Самокат - на главную страницу Самоката;

Особенности:
- Page Object Model: все действия вынесены в классы в папке pages;
- BasePage: содержит общие методы ожидания, скролла и взаимодействия с элементами;
- Локаторы: на каждый блок тестов были созданы и разделены локаторы;
- Параметризация: используется @pytest.mark.parametrize;
- Allure: шаги формируются через @allure.step в методах PageObject; заголовки тестов — через @allure.title и описание тестов через @allure.description.
